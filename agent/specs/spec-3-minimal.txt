Build a read-only Car Inventory viewer as a React 19 + TypeScript application
on top of the provided boilerplate (Apollo Client, MUI, and MSW are already
wired up — reuse them).

Mandatory, and this is the full scope — do not add anything beyond this list:
1. Fetch and display the list of cars using the GetCars GraphQL query.
2. Provide a search bar that filters the displayed cars by model.
3. Present each car in an MUI Card showing make, model, year, and color.
4. Render the car image at the correct responsive breakpoint: "mobile" at
   viewport widths of 640px or less, "tablet" between 641px and 1023px, and
   "desktop" at 1024px and above.
5. Extract the GraphQL data-fetching logic into a useCars() custom hook.
6. Include unit tests for the search logic and for at least one component
   that renders car data.

Explicitly out of scope for this version — do not build these:
- No sorting controls of any kind.
- No "Add Car" form and no AddCar mutation usage.
- No year filter, no GetCar single-car query, no useCarFilters hook.

Do not add a real backend, database, authentication, or deployment
configuration — the MSW mocks already configured in this boilerplate are the
only data layer. Do not modify package.json, tsconfig.json, or any
vite/vitest config file.
